# MILUN Studio

Portfolio of architectural pop-up cards by MILUN Studio (Paris).

- `index.html`: the portfolio page (GitHub Pages).
- `img/`: web images of each piece.
- `video/`: opening videos.
- `ig/`: Instagram media (Reels and carousels) used by the post scheduler.
